# Goark Boot 0.0.1

English | [中文](https://github.com/goark-projects/goark-boot/blob/v0.0.1/docs/releases/v0.0.1.zh-CN.md)

Release date: September 7, 2026

Goark Boot 0.0.1 is the first public convention and startup layer for Goark.
It assembles explicit auto-configurations and deterministic configuration data
without runtime classpath scanning.

See the [changelog](https://github.com/goark-projects/goark-boot/blob/v0.0.1/CHANGELOG.md#001---2026-09-07)
for the concise version history.

## :star: New Features

- Start Goark applications with ordered, explicit auto-configuration.
- Discover YAML, Java properties, and TOML application configuration.
- Layer base files, Boot Profiles, process environment, command-line
  properties, and explicit Go options with deterministic precedence.
- Support active, included, default, and grouped Profiles.

## :information_source: Profile Boundary

Boot Profiles select runtime application configuration such as `dev` or
`production`. A CLI build Profile selects build arguments and environment;
it can activate a Boot Profile through `GOARK_PROFILES_ACTIVE`, but the two
concepts remain independently owned.

## :package: Installation

```bash
go get goark.dev/boot@v0.0.1
```

Go 1.26 or later and Goark Core 0.0.1 are required.

## :white_check_mark: Verification

The candidate passed tests, vet, and race gates on Windows Go 1.26 and Debian
Linux Go 1.27. CI covers Linux, Windows, and macOS.
