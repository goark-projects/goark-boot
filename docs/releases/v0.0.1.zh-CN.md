# Goark Boot 0.0.1

[English](https://github.com/goark-projects/goark-boot/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Goark Boot 0.0.1 是 Goark 首个公开的约定与启动层。它通过显式自动配置和确定性
配置数据装配应用，不使用运行时 classpath 扫描。

精简版本历史见[变更日志](https://github.com/goark-projects/goark-boot/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-06)。

## :star: 新功能

- 使用有序、显式的自动配置启动 Goark 应用。
- 发现 YAML、Java properties 和 TOML 应用配置。
- 按确定性优先级分层合并基础文件、Boot Profile、进程环境、命令行属性和显式 Go 选项。
- 支持激活、包含、默认和分组 Profile。

## :information_source: Profile 边界

Boot Profile 选择 `dev`、`production` 等运行时应用配置。CLI 构建 Profile 选择
构建参数和环境；它可以通过 `GOARK_PROFILES_ACTIVE` 激活 Boot Profile，但两者
仍由不同模块独立负责。

## :package: 安装

```bash
go get goark.dev/boot@v0.0.1
```

要求 Go 1.26 或更高版本，并依赖 Goark Core 0.0.1。

## :white_check_mark: 验证

候选版本已在 Windows Go 1.26 和 Debian Linux Go 1.27 上通过测试、vet 和 race。
CI 覆盖 Linux、Windows 和 macOS。
